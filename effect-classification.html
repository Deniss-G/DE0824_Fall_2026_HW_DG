Audio effect classification

Below is a comprehensive list and classification of audio processing effects.

  • Dynamics — signal loudness / dynamic range

    Effects that react to or manipulate signal level.

    • Compressor — reduces dynamic range
    • Limiter — prevents signal from exceeding a threshold
    • Brickwall limiter — extremely strict peak limiting
    • Expander — increases dynamic range
    • Downward expander — makes quiet signals quieter
    • Upward expander — makes loud signals louder
    • Noise gate / gate — attenuates or mutes signals below a threshold
    • Ducker — lowers one signal when another is present
    • De-esser — frequency-selective compression of sibilance
    • De-plosive / dynamic low-frequency suppression
    • Multiband compressor
    • Multiband limiter
    • Multiband expander
    • Dynamic EQ
    • Upward compressor — raises quieter material
    • Parallel compression
    • Sidechain compression
    • Transient shaper / transient designer — changes attack and sustain
    • Leveler / automatic gain control (AGC)
    • Volume rider / automatic fader
    • Maximizer — limiting + level maximization
  • Spectral filtering — frequency content

    Effects that alter the frequency spectrum.

    • Equalizer (EQ)
    • Graphic EQ
    • Parametric EQ
    • Semi-parametric EQ
    • Shelving EQ
    • Low-shelf filter
    • High-shelf filter
    • Peaking / bell filter
    • Low-pass filter (LPF)
    • High-pass filter (HPF)
    • Band-pass filter (BPF)
    • Band-stop / band-reject filter
    • Notch filter
    • All-pole / resonant filter
    • Comb filter
    • Tilt EQ
    • Loudness EQ
    • Tone control
    • Presence control
    • Resonant filter
    • Formant filter
    • Vowel filter
    • Filter bank
    • Crossover
    • Multiband crossover
    • FIR filter
    • IIR filter
    • Linear-phase EQ
    • Minimum-phase EQ
    • Matched EQ / spectrum matching
    • Auto-filter / envelope filter
    • Wah-wah
    • Talk-box/formant-style filtering
    • Spectral shaping / spectral EQ
  • Clipping & Distortion — nonlinear processing

    Effects that change the waveform through nonlinear processing, usually generating new harmonics.

    • Clipping
    • Hard clipping
    • Soft clipping
    • Overdrive
    • Distortion
    • Fuzz
    • Saturation
    • Tape saturation
    • Tube / valve saturation
    • Transformer saturation
    • Console saturation
    • Preamp saturation
    • Analog-modelled distortion
    • Waveshaping
    • Wavefolding
    • Rectification
    • Asymmetric distortion
    • Harmonic exciter
    • Harmonic enhancer
    • Bit crusher
    • Bit-depth reduction
    • Sample-rate reduction / downsampling
    • Digital clipping
    • Lo-fi degradation
    • Aliasing distortion
    • Speaker / cabinet distortion
    • Amp simulation
    • Guitar amp distortion
    • Tape overdrive
  • Delay & time effects — copies of the signal

    Effects based primarily on delayed copies of the original signal.

    • Delay
    • Digital delay
    • Analog delay
    • Tape delay
    • Single-tap delay
    • Multi-tap delay
    • Stereo delay
    • Ping-pong delay
    • Slapback delay
    • Echo
    • Feedback delay
    • Cross-feedback delay
    • Filtered delay
    • Modulated delay
    • Rhythmic / tempo-synced delay
    • Reverse delay
    • Granular delay
    • Freeze delay
    • Haas delay / precedence effect
    • Automatic double tracking (ADT)
    • Doubling / double-tracking effect
    • Micro-delay / stereo widening
    • Looper — long-duration repetition rather than a conventional effect
    • Comb filtering — very short delay + original signal

    Chorus, flanger and some phasers are also delay-related, but it is usually more useful to classify them under modulation.

  • Reverb — simulated acoustic persistence

    Technically constructed from delays/reflections, but important enough to be its own category.

    • Room reverb
    • Hall reverb
    • Chamber reverb
    • Plate reverb
    • Spring reverb
    • Cathedral reverb
    • Ambience reverb
    • Early-reflections processor
    • Algorithmic reverb
    • Convolution reverb
    • Impulse-response (IR) reverb
    • Nonlinear reverb
    • Gated reverb
    • Reverse reverb
    • Shimmer reverb
    • Modulated reverb
    • Infinite / freeze reverb
    • Bloom reverb
    • Cloud / ambient reverb
    • Granular reverb
    • Ducked reverb
    • Dynamic reverb
    • Hybrid reverb
    • Surround / immersive reverb
  • Modulation — parameters changing over time

    Effects where an oscillator, envelope, audio signal, etc. modulates some property of the signal.

    • Chorus — modulated short delays
    • Flanger — very short modulated delay + feedback
    • Phaser — modulated phase-shift stages
    • Tremolo — amplitude modulation
    • Vibrato — pitch modulation
    • Rotary speaker / Leslie
    • Auto-pan
    • Panner
    • Ring modulation
    • Amplitude modulation (AM)
    • Frequency modulation (FM)
    • Frequency shifter
    • Pitch modulation
    • Filter modulation
    • Auto-wah
    • Envelope filter
    • LFO-controlled filter
    • LFO-controlled delay
    • Modulated reverb
    • Scanner / scanner vibrato
    • Uni-Vibe
    • Doppler effect
    • Rhythmic gating / trance gate
    • Chopper
    • Stutter modulation
  • Noise reduction — unwanted-signal removal

    Effects/processors intended to remove noise, interference or unwanted components.

    • Noise reduction / denoiser
    • Broadband denoising
    • Spectral denoising
    • Adaptive noise reduction
    • Noise profiling / noise-print reduction
    • Noise suppression
    • Hum removal
    • De-hum
    • 50/60 Hz mains hum filtering
    • Buzz removal
    • Hiss reduction
    • De-click
    • De-crackle
    • De-pop
    • De-plosive
    • De-rustle
    • De-wind
    • De-reverb
    • De-bleed
    • Feedback suppression
    • Automatic feedback elimination
    • Interference removal
    • Spectral repair
    • Audio restoration
    • Dialogue isolation
    • Voice isolation
    • Source separation
    • Background-noise suppression
    • AI/ML noise suppression
    • Noise gate — overlaps with dynamics
    • Downward expander — overlaps with dynamics
  • Phase & polarity

    Processing concerned primarily with phase relationships, timing alignment and polarity.

    • Polarity inversion / polarity reverse
    • Phase inversion — often used informally for polarity inversion, though technically different
    • Phase shift
    • Phase rotator
    • All-pass filter
    • Variable phase adjustment
    • Phase alignment
    • Automatic phase alignment
    • Time alignment
    • Sample alignment
    • Delay-based phase alignment
    • Phase correction
    • Phase matching
    • Linear-phase processing
    • Minimum-phase processing
    • Phase dispersion
    • Phase rotation
    • Stereo phase adjustment
    • Mid/side phase manipulation
    • Correlation correction
    • Comb-filter correction
    • Speaker/driver phase alignment
